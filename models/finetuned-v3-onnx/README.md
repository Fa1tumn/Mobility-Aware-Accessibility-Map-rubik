# 캠퍼스 재질 파인튜닝 3차 — 현장 시험용

Material 3차 학습의 최종 5에폭 모델과 기존 Area 7에폭 모델입니다. CPU ONNX Runtime으로 실행합니다. NPU 변환 모델은 아닙니다.

## 2차와 달라진 점

- 교내 학습 사진 93장. 이 중 22장이 새로 넣은 11/25 주행의 비블록 사진입니다 (판석, 어두운 빨간 길, 밝은 빨간 길, 회색 아스팔트). 차도만 찍힌 3장은 재질 영역이 없어 빠졌습니다.
- 라벨 기준: 빨간 길은 아스팔트, 판석은 기타로 표시했습니다. 빨간 길이 자전거 도로인지 보행로인지는 현장 표시가 없어 확정하지 못했습니다.
- 비블록 재질이 들어간 사진 33장을 한 에폭에 20번 더 넣었습니다.
- 교내 사진에 밝기(0.55~1.2배)·대비·색 변화와 흔들림 번짐(3~13픽셀)을 무작위로 넣었습니다.
- 그 밖의 설정(원본 2000장, 교내 사진 10회 반복, 5에폭, 배치 4, 학습률 3e-5)은 2차와 같습니다.

## Pi 실행

저장소 루트에서 실행하세요. 기존 수집 프로그램은 먼저 종료하세요.

```bash
git fetch origin
git switch feat/finetuned-v3
git pull --ff-only
git lfs pull
python -m pip install onnxruntime
INFERENCE_BACKEND=onnxruntime MODEL_DIR="$PWD/models/finetuned-v3-onnx" python main.py
```

현재 장치의 가상환경에서 실행하세요. 기존 GPS·IMU·프레임 저장 환경변수는 그대로 유지합니다. 수집 결과의 model_version은 `campus-material-ft-v3-20261127-e5`여야 합니다.

2차 모델로 돌아가려면 `MODEL_DIR`만 `models/finetuned-v2-onnx`로 바꾸세요. 기본 모델과 기본 backend는 변경하지 않았습니다.

## 근거와 한계

- 학습 run: material-v3-20261127-084912, 최종 epoch 5. Area는 재학습하지 않았습니다.
- 원래 검증셋 mIoU: 기존 68.22%, 2차 69.69%, 3차 66.44%. 허용 하한(기존 - 2%p = 66.22%)을 겨우 넘었습니다. 4에폭은 65.71%로 하한 아래였습니다.
- 원래 검증셋에서 떨어진 재질: 우레탄 62.6% → 58.6%, 기타 69.2% → 61.1%, 흙·돌 54.6% → 52.7%. 빨간 길을 아스팔트로 배우면서 원래 데이터의 빨간 우레탄을 덜 맞히는 것으로 보입니다.
- 11/25 주행, 2초마다 고정 1장 분석, 그 위치 10m 칸 정답과 같은 비율: 기존 50.0%, 2차 80.8%, 3차 90.0%.
  - 블록 343건: 2차 323건, 3차 320건 정답. 블록 성능은 유지됐습니다.
  - 비블록 69건: 2차 10건, 3차 51건 정답. 그러나 11/25 비블록 사진 22장을 학습에 썼으므로 독립 평가가 아닙니다.
  - 어두운 빨간 길은 학습했는데도 프레임의 41%를 블록으로 판정합니다.
- 비블록 성능은 11/25에 가지 않은 길이 포함된 새 주행으로 판단해야 합니다. 같은 프레임으로 2차와 3차를 비교할 수 있게 프레임 원본을 저장하세요.
- thresholds: Area sidewalk >= 0.8 AND Material >= 0.8. 계단·파손 출력은 없습니다.
- Pi의 새 모델 실행 및 처리 시간은 아직 검증 전입니다. 모델 추론 성공과 버전 기록을 확인한 뒤 수집하세요.

ONNX 파일은 Git LFS로 관리합니다. checksums.json은 SHA256, training-metrics.jsonl은 에폭별 원래 검증셋 결과, export-verification.json은 PyTorch 체크포인트와 ONNX 출력 비교 결과입니다.
